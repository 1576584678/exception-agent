# Exception Insight v0.1.0 · 异常分析平台

> 粘贴一段报错或上传报错截图，自动从日志平台拉取相关日志、定位到代码行与最近提交人，输出一份**带可回溯证据的归因报告**。平台只给排查建议，**不自动改代码、不改数据**。

## 这个版本能做什么

- **配置入口，不硬编码**：全局模型（OpenAI 兼容网关，可指向私有化部署）+ 多项目（每个项目独立配置日志源 / 代码仓库 / 分支）；仓库地址、模型、项目都可在界面配置。
- **单点输入分析**：粘贴报错文本或上传截图，一键提交（Ctrl+Enter 快捷提交）。
- **六阶段异步分析**：解析 → 检索计划 → 日志采集 → 代码归因 → 数据核查 → 生成报告，前端实时轮询展示每阶段状态与耗时。
- **证据链可追溯**：结论挂证据（日志片段、代码位置、提交人），支持折叠 / 分页展开。
- **多日志源 / 多仓库**：VictoriaLogs、Elasticsearch、Loki 日志源；GitLab、GitHub 代码仓库；项目、记录均可删除。
- **深色模式 + 响应式**：顶栏项目切换、配置抽屉、分支徽标。
- **安全基线**：三道脱敏闸、外部系统只读 + 白名单、凭证只存引用不落库明文、审计不可篡改、Prompt 注入隔离。

## 快速开始

```bash
npm install
cp .env.example .env        # 填 JWT_SECRET，可选填 LLM 网关地址 / Key
npm run build
npm start                  # 默认 http://localhost:3000
```

浏览器打开 → 用默认账号 `1001 / dev123` 登录（仅内网试用，请尽快改默认凭证）→ 新建项目并配置日志源与仓库 → 粘贴报错开始分析。

**分发给同事**：`npm run pack` 生成 `release/exception-insight.zip`（含编译产物 + 生产依赖 + 启动脚本，不含任何密钥与真实配置）。

## 边界与已知事项（诚实说明）

- 默认账号 `1001/dev123` 为演示账号，上线前请改默认凭证或加首次登录强改密。
- 当前为内存态存储（重启清空）；接 PostgreSQL 只需新增仓储实现，业务层零改动（详见 `AGENTS.md`）。
- `npm audit` 显示 6 个依赖漏洞（含 1 个 critical：`fast-jwt`），生产部署前请评估升级。
- 暂不支持多租户隔离，仅适合团队内网试用。
- 文档与示例中的人物 / 工号 / 订单号均为虚构，仅用于说明。
